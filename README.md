📘 Fetching Data - API Data Fetching App
📋 Description

A simple application that fetches data from an external API using JavaScript and displays it in an organized way with pagination.
This project is designed to practice working with APIs, fetching data, and rendering it interactively on the UI.

✨ Features

🔄 Fetch data from Reqres API

👨‍🏫 Display teachers in styled cards

📄 Pagination to navigate between pages

⚠️ Error handling for API requests

⏳ Loading state indicator

🎨 Responsive design for all screen sizes

🛠️ Technologies Used

HTML5

CSS3

JavaScript (ES6+)

Reqres API


💻 Installation
git clone https://github.com/Doha-2004/Fetching-Data.git
cd Fetching-Data
# Open index.html in your browser
